# Assumptions and limitations

- An invoice price below list may be legitimate only up to the approved discount stored for the product.
- Recoverable leakage is an estimate. It should be reviewed before outreach or credit action.
- Returns are treated as margin leakage for prioritisation but are not necessarily preventable.
- The sample has a fixed generation seed for reproducible results.
- Production should use a durable warehouse, audit logs, policy versioning, and an authorised return-reason taxonomy.
