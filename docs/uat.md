# UAT checklist

| Test | Expected result |
|---|---|
| Refresh source data | Quality report is produced with row and value reconciliation. |
| Select High risk | Dashboard only shows orders with score ≥ 70. |
| Inspect an exception | Reason and recoverable amount are populated. |
| Compare source / curated | Difference is at most $0.01. |
| Filter a region | KPI cards and table update consistently. |
